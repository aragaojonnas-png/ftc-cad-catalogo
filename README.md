# FTC_CAD - catalogo de pecas STEP (goBILDA, REV, AndyMark)

Aplicativo para Windows: abre o catalogo, atualiza sozinho pelo GitHub, baixa cada peca quando voce clica nela e
cuida das pecas da equipe (pasta do Google Drive).

**Usar:** baixe o zip de instalacao, extraia, abra `FTC_CAD.exe`.
**Desenvolver:** veja `CLAUDE.md`. Codigo em `src/FtcCad.cs`, compilar com `./build.sh`.
