# FTC_CAD - catalogo de pecas STEP (goBILDA, REV, AndyMark)

Aplicativo para Windows (`FTC_CAD.exe`, janelas nativas, sem PowerShell). Abre o catalogo, atualiza sozinho pelo GitHub,
baixa cada peca quando voce clica nela e cuida das pecas da equipe (pasta do Google Drive).
O codigo-fonte e `FtcCad.cs` (C#, .NET Framework 4.5+, ja vem no Windows 10/11).
